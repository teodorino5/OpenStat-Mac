# Changelog

## 0.1.0 — unreleased

- Added the original public-source audit and phase-gated implementation plan.
- Added the Python 3.12 data foundation, immutable Parquet bases, sparse edit revisions, bounded JSON/Arrow pages, framed JSON-RPC, CLI and native project integrity checks.
- Added the Swift/AppKit/SwiftUI contributor application with editable grid, metadata inspector, project save/open and undo hooks.
- Added English/Czech String Catalog, Python acceptance tests, Swift unit tests and a Command Line Tools integration smoke executable.
- No statistical analysis procedures or portable release runtime are available yet.

### Added — Arrow viewport slice

- Original bounded Swift Arrow IPC reader and off-actor native transfer with checksum, schema, size and row-ID validation.
- Explicit 32 MiB engine artifact budget and release after native decoding.
- Original typed interoperability inputs, exact bit-pattern assertions, truncation and corruption checks.

### Fixed

- Reset the selected variable after importing a dataset with different field IDs.
- Display Arrow errors using English/Czech catalog keys.

### Added — native data controls

- Append blank cases and nullable variables with original immutable revision files, stable IDs and retained sparse cell edits.
- English/Czech forms for physical storage and CSV/TSV delimiter/decimal options, with undoable import.
- Integration checks for case/variable insertion, signed integer precision on save/reopen and import undo.

### Fixed

- Reject reserved internal column IDs before writing a duplicate Arrow schema.

- Restore a valid inspector selection when undo returns to a dataset with different field IDs.
- Preserve negative zero through cell editing, Foundation JSON-RPC output and saved sparse edits.
